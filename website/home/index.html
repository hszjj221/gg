gg

用 Go 写的开源个人 AI agent。它住在终端、浏览器和聊天软件里，连接 OpenAI-compatible 接口，把会话存成 JSONL，也能记住你是谁。 gg is an open-source personal AI agent written in Go. It lives in the terminal, the browser, and messenger apps, talks to OpenAI-compatible APIs, stores sessions as JSONL, and remembers who you are.

  • 终端、Web 与 Electron 共用同一套 Go 会话运行时。 The CLI, Web, and Electron clients share one Go conversation runtime.
  • 内置 read、list、grep、bash、edit、write，以及记忆、定时任务和第三方连接器。 Built-in read, list, grep, bash, edit, and write, plus memory, scheduled jobs, and third-party connectors.
  • 在终端里，bash、edit、write 会先征求同意。明显只读的 shell 命令可以直接跑。 In a terminal, bash, edit, and write ask before they run. Clearly read-only shell commands do not.
  • 危险 shell 命令必须交互确认。没有终端时，即使加上 --yolo 也会被拒绝。 Dangerous shell commands always need an interactive approval, and stay denied under --yolo when there is no terminal.
