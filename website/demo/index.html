终端里几种颜色对应不同来源： Colors in the terminal mark where each line comes from:

  • 浅色正文是 stdout，包括交互横幅、你的输入行和最终回答。 Light text is stdout: the interactive banner, the typed line, and the final answer.
  • 斜体暗色是思考过程，CLI 把它写到 stderr。 Dim italics are thinking, which the CLI writes to stderr.
  • 暖色是 stderr 上的审批或拒绝，文句与 cliapp 里打印的一致。 Warm text is an approval or a denial on stderr, in the words cliapp prints.
  • 金色是 tool_call_start / tool_call_finish。运行时会发出这些事件，逐行 CLI 不打印它们，这里是为了把工具调用展示出来。 Gold lines are tool_call_start / tool_call_finish. The runtime emits them. The line CLI does not print them; they are shown here so the tool calls are visible.
  • 绿色是回放自己的说明，不是 gg 的输出。 Green lines are notes from this replay, not gg output.
